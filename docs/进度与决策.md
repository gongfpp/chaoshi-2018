### 关键决策

| 决定 | 理由 | 影响 |
| --- | --- | --- |
| 城市定杭州，2018.3 开篇 | 有真实劳动地理（五堡、九堡、乔司、钱江新城）与可查的房租、通勤距离；2018 年外卖大战与 2021 年区划调整可作时代锚点 | 空间与成本可核算；区划调整成为第 15 章的制度细节 |
| 主角设为"专送转众包" | 两种用工模式的规则不同，混用会失真 | 第 7 章后逐步转众包，失去工伤保障成为主题的一部分 |
| 三次失车＝偷车／扣车＋私了／卖车葬妻 | 对应原作三次剥夺，但每次原因不同：运气、规则、家庭 | 避免"照搬事件"，让结构性原因逐层显现 |
| 虎妞改为"真怀孕＋隐瞒病史＋拒绝建档" | 现代有产检，假孕不成立；死亡需多重失效叠加 | 第 11—12 章的因果链可核查 |
| 小说源文件内嵌 HTML 注释作为演出指令 | 同一份文件既是可读小说，也是游戏脚本源，杜绝两份文本分叉 | 改动正文即改动游戏；对应表自动生成 |
| 立绘采用"羽化叠层"而非抠图 | 生成模型的 alpha 边缘不稳定；羽化后与背景融合更稳 | 统一视觉语言，避免毛边 |
| 音频全部程序化合成 | 无版权风险、可复现、体积可控 | 风格偏环境音，非旋律配乐 |
| 结局三分支 | 主线保留小说的"降级"结局；两个替代结局分别对应"进入系统"与"退出系统" | 选择有现实依据，代价明确 |
