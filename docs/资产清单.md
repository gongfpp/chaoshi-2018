# 资产清单

所有图像由本机图像生成工具产出（2026-10-19），原图保留在 `build/art_raw/<id>/`，经 `tools/finish_art.py` 裁切（背景 16:9 → 1280×720，立绘 2:3 → 520×900 并做边缘羽化）。

## 视觉规范

- 画风：写实电影感数字绘画，35 mm 胶片颗粒，纪实摄影构图
- 色彩：低饱和冷灰蓝为主调，钠灯暖黄作点缀；红色只用于喜宴与霓虹，避免情绪化
- 人物：半身像，中性表情，纯净深灰蓝背景，柔和侧光；同一角色固定服装与光线
- 界面：墨黑（#0A0C10）／面板（#14181D）／暖白（#E8E4DC）／琥珀（#C79A4B）
- 字体：正文 Noto Serif SC，界面 Noto Sans SC

## 音频（41 BGM + 4 音效）

全部由 `tools/gen_audio.py` 用 NumPy 合成（噪声整形 + 带通滤波 + 正弦簇 + 卷积混响 + 首尾交叉淡化），44.1 kHz 立体声 OGG（Vorbis q2）。无第三方采样。

- 医院：hospital_day / hospital_night / hospital_low / hospital_tense
