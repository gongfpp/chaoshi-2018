# 引擎与技术选型

决定日期：2026-10-19。选定：**Ren'Py 8.5.3**（官方稳定版，2026-05-15 发布）＋官方 Web 平台支持包（renpy-8.5.3-web.zip）。本机路径 `~/Developer/Tools/renpy-8.5.3`。

## 一、比较矩阵

| 维度 | Ren'Py 8.5.3 | Godot 4 + Dialogic 2 | 自研 Web 引擎 |
| --- | --- | --- | --- |
| 长篇中文文本组织 | 原生：label/jump、`nvl`、`say` 语句；单文件可上万行，脚本即文本 | 需经 Dialogic 时间轴/资源，长篇维护成本高 | 需自建 DSL 与解析器 |
| 分支与变量 | 原生 menu/if/jump，`persistent`、变量存档自动处理 | Dialogic 有分支但状态管理需手写 | 全部自建 |
| 存读档／历史／自动／快进／文字速度 | **引擎内置且成熟**，含 rollback | 需插件或自建 | 全部自建（回滚、跨版本存档兼容尤其难） |
| 演出控制 | ATL 动画、`with` 转场、`show/hide`、图层、视差 | 强（节点/着色器），但超出本项目需要 | 需自建 |
| 素材接入 | 图片/音频/视频原生，ATL 处理缩放与位置 | 强 | 需自建 |
| 中文排版 | 支持 TTF/OTF；需自备 CJK 字库；支持 `layout` 断行 | 支持，但 UI 需手调 | 依赖浏览器，最省事 |
| 构建发布 | `distribute` 出 Mac/Win/Linux/Web | 导出 Web/桌面均可 | 天然 Web |
| 本机测试能力 | `lint` 静态检查、`--compile`、8.5 新增自动化测试框架、Web 构建可本地起服务 | 需开编辑器，自动通关测试弱 | 需自建测试 |
| 风险 | Web 构建体积较大（wasm ~30MB），首次加载慢 | 版本迭代快，Dialogic 2 与 Godot 4.x 小版本兼容问题多 | 工作量与缺陷风险最高 |

## 二、取舍理由

1. 本项目 95% 的价值在文本与演出节奏，不在自定义系统。Ren'Py 把存读档、历史、自动、快进、文字速度、音量、返回标题全部内置，等于直接满足验收条款中的"基本阅读功能"。
2. 目标是"明天可验收"：Ren'Py 的脚本即纯文本，可用外部脚本从小说源文件批量生成，避免手工在编辑器里搭节点；Dialogic 的资源化流程会显著增加机械劳动。
3. 交付需要"无需安装开发环境即可体验"：Ren'Py 官方 Web 支持包可直接产出浏览器版本；同时可产出 macOS 应用包。
4. 独立开发者社区经验（r/renpy、Lemma Soft Forums、Ren'Py 官方文档）一致指出：长篇项目的主要失败原因是脚本组织与素材规范，而非引擎能力；Ren'Py 的 `label` + 外部生成脚本正好对症。
