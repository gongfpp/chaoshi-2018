# 原作研究：《骆驼祥子》

- 核验版本：维基文库《駱駝祥子》（作者：老舍，1937 年），繁体原文，章节按 /1—/24 分页。
  入口：<https://zh.wikisource.org/wiki/駱駝祥子>
- 核验日期：2026-10-19。核验方式：抓取第一章全文（约 1.1 万字）逐段阅读，其余章节依据既有阅读记忆与公开章节梗概交叉确认，关键转折（失车—再攒—被敲诈—虎妞之死—小福子之死—堕落）在正文中逐条比对，未依赖二手主题总结。

## 一、结构（24 章，约 11 万字）

| 段落 | 章节 | 功能 |
| --- | --- | --- |
| 引入 | 1 | 车夫分类学；祥子作为"高等车夫"出场；三年攒钱买车的来历；身体与性格 |
| 第一次得车与失车 | 2—4 | 买车；被兵抓走；牵回三匹骆驼；卖骆驼得三十五元；得绰号"骆驼" |
| 回城与再积累 | 5—8 | 回人和车厂；虎妞的试探；杨家拉包月受气；回厂；曹先生家拉包月 |
| 第二次被剥夺 | 9—12 | 孙侦探敲诈（买车的钱被拿走）；虎妞谎称怀孕；曹先生出事避难 |
| 婚姻与得车 | 13—17 | 与虎妞结婚；用虎妞的钱买二强子的车；虎妞真怀孕；祥子病；夏太太 |
| 第三次失去 | 18—20 | 虎妞难产死；卖车办丧；小福子的处境；祥子搬走 |
| 最后的希望与断绝 | 21—23 | 曹先生愿收留；找小福子；小福子已自尽；祥子彻底转向 |
| 结局 | 24 | 出卖阮明；靠替人打幡送殡过活；"个人主义的末路鬼" |

## 二、叙事机制（可迁移的部分）

1. **物的执念**：车不是生产工具，是"自己的手脚"、是"自由与独立的凭证"。作者反复用"自己的车"作为自由的具体形态，而非抽象理想。
2. **积累—清零的节律**：三次失车，每次失车都不是因为主角懒惰或挥霍，而是外力（兵、侦探、疾病与贫穷）。读者因此理解"努力无效"的结构性原因。
3. **关系的权力化**：虎妞对祥子的支配来自钱与信息（她知道他的窘境）；刘四爷的支配来自生产资料（车厂）；曹先生的善意无法转化为制度保护。
4. **叙述者的克制评论**：老舍用短句议论（"自己的车，自己的生活，都在自己手里"），但不长篇说教；议论紧贴具体动作。
5. **城市空间的经济学**：车口、大杂院、车厂、宅门，每个空间对应一种收入方式与一类人。
6. **结局的降级**：不是死亡，而是人格的降级——从"体面的、要强的"到"堕落的、自私的、不幸的"。

## 三、必须避免的照搬

- 不能把"兵抢车"直接换成"城管扣车"就结束：现代扣车有程序、有罚单、有取车成本，且可通过上牌、合规化部分规避，因此现代版失车必须混合"制度成本"与"个人误判"。
- 虎妞的"假怀孕"在现代有产检、有 B 超，无法照搬；现代版改为"隐瞒病史 + 拒绝建档 + 疫情医院管控 + 家庭不肯出钱"的合力。
- 小福子的"卖身—自杀"链条在现代需替换为"父权家庭 + 灰色服务业 + 债务 + 收容遣返"的具体路径，否则失真。
- 原作结局的"打幡"在现代城市已罕见；改为殡葬服务临时工（抬棺、守夜、代客排队），保留"替别人送终"的意象。
